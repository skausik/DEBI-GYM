## 📋 About

Debi Gymnasium is Jhargram's top-rated fitness centre with a **5.0 ★ rating** on Justdial.  
This website showcases their services, timings, location, and contact details with a fully animated, mobile-responsive UI.

**Owner & Trainer:** Kaliprasad Roy (M.D.P.C.A. Affiliated)

---

## ✨ Features

- ⚡ Fully animated hero section with floating particles & gradient orbs
- 📞 One-tap **Contact Us** button (opens phone dialer)
- 🗺️ **Get Directions** button (opens Google Maps)
- 🕐 Live IST clock with real-time open/closed status
- 🏋️ Services grid — Strength, Cardio, Personal Training & more
- 📍 Embedded Google Maps location
- 🎨 Bright, modern theme with smooth scroll animations
- 📱 Fully responsive (mobile + desktop)
- 🖱️ Custom animated cursor
- 🔴 Animated ticker banner

## 🚀 Deploy

### GitHub Pages (Free)
1. Go to repo **Settings → Pages**
2. Source: `main` branch / `/ (root)`
3. Save → live at `https://skausik.github.io/DEBI-GYM`

### Vercel (Free)
1. Import repo at [vercel.com](https://vercel.com)
2. Deploy instantly — no config needed
